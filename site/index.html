A context hub for long-running projects.

Capture a fragment the moment it appears — a good AI answer, a decision buried in an email, a half-formed thought. Spool threads your fragments by project and packs any thread into a paste-ready briefing, so you can re-enter a project — or re-brief an AI — instantly.

The core loop

Capture → Thread → Pack

LLMs do not remember your project. Every new conversation, you re-explain the context. Across many AIs, tabs, and days, a project's context gets shredded — and reassembling it falls on your memory. Spool compresses “re-explaining” into a single paste.

01 · CAPTURE

One keypress, no decisions

Double-tap ⌥ grabs whatever you just copied and files it into the current thread. A quiet overlay confirms the save on whatever screen you're on — the main window never has to come forward.

→
02 · THREAD

A log, not a chat

An append-only timeline of fragments per project. Two tiers only — Workspace → Thread — no infinite nesting. The newest blocks are “where you left off”; there is no status note to maintain.

→
03 · PACK

Paste-ready context

One click assembles the thread into a Markdown briefing with full provenance. Pure string assembly — deterministic, no AI in the hot path. Paste it into any AI, or read it yourself.

What makes it different

Three commitments

Zero-friction capture

Capture rides your existing ⌘C muscle memory — copy, then double-tap ⌥. No window switch, no dialog, no decisions at capture time. Sources are detected automatically, down to the browser tab you copied from.

Provenance-faithful packs

Every block carries where it came from and when. A pack sorts content by authority — your own words rank highest, references stay references — so the AI reading it knows what to trust. Same thread, same day, same bytes: packing is deterministic.

AI as librarian, not author

Connect Claude Desktop, Cursor, or any MCP client and your AI can read, search, and file into your library — every write attributed, append-only. What you wrote by hand is never overwritten. Ships with zero built-in AI: no keys, no cloud.

Pack, then paste anywhere

Works with any AI — or none

A pack is plain Markdown. Paste it into ChatGPT, Claude, Gemini, a code assistant, or an email to a colleague. MCP hookup is optional and off by default; Spool is fully functional with nothing configured.

Packing a thread: choose intent and range, copy, paste. No AI in the loop.

Privacy

Your data stays on your machine. No exceptions.

  • No account, no server, no telemetry, no crash reporting
  • Everything lives in a local SQLite file you can copy or delete
  • The app's content-security policy structurally blocks all outbound network requests
  • Data leaves only when your MCP client reads it — behind two opt-in switches
