### 1.1 ⚠️⚠️ 隐私政策改了口径,这是这一窗最要紧的一处

**原文只说一条出网路径(MCP 客户端),而 v0.4.0 有两条。**

引擎位(压缩 / 去重 / 跟进 / 周回顾)会启动 `claude` / `codex` 子进程并把块内容交给它,
**而「跟进」这个动作是明确要联网搜索的**。三份隐私文件原先一个字都没提。

**改成的口径(三处一致)**:

> **Spool 自己一次都不出网。** 有两种情况会让内容离开这台电脑,两种都默认关闭、
> 需要你亲手开启,而且两种里出网的都是**你自己装的、你自己登录的那个程序**,不是 Spool。

加了一行表格(引擎位)+ 一句醒目提示(**只有「跟进」会主动联网,另外三个动作不开联网工具**)。

⚠️ **这不是「破了零出网」** —— Spool 本体和 webview 仍然零 HTTP,CSP 也没动。
**破的是「只有 MCP 一条路」这个旧说法。** README 的设计原则第 2 条同步改了。

⚠️ **以后改隐私,三处一起改,别只改一处**:`docs/PRIVACY.md`、`site/privacy.html`、
`scripts/site-zh-privacy.html`,**最后跑 `node scripts/build-site-zh.mjs`**
(`build-site-zh.test.mjs` 会拦住忘跑的情况)。

> 「我认为**工作流在发生变化**,spool 逐渐会变成**用户在 MCP 端进行对话,block 被 MCP

### 6.5 golden fixture 重生(硬规则 5)
