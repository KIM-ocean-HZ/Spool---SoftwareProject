### 1.2 项目管理:点一行不再跳转了

**点一行 = 展开**,跳转是展开里的一个按钮。这是 Ocean 那条要求本身带来的取舍:
一张卡只有一个动作,点击就可以**是**那个动作;一行有五个,点击只能是「把五个给我看」。

展开里:`{n} 块 · {n} 字` + **跳转 / 打包 / 问 AI / 完成或重新打开 / 删除**。

⚠️ 三个新东西:

## 2. 这一窗真机测出来的事(都花过钱,别再重复探)

一共约 **$0.40**(全 haiku)。

### 2.1 ⚠️⚠️ effort:这一版 CLI 根本用不了 —— 这是测量结果,不是猜的

Ocean 问「为什么没有 effort」。查下来两层:

**第一层:没有 `--effort` 参数,所以找不到是正常的。** 控制走**环境变量**,
从他机器上装的 claude 2.0.50 二进制里读出来的:

```js
let T = process.env.CLAUDE_CODE_EFFORT_LEVEL;
if (T) { if (T === "unset") return; …; if (["low","medium","high"].includes(T)) return T }
```

**第二层(真跑测的,这才是关键):这一版 CLI 够得着的模型全都不支持它。**

```
CLAUDE_CODE_EFFORT_LEVEL=low claude -p "…" --model haiku
  → API Error: 400 "This model does not support the effort parameter."
  --model sonnet  → 同样的 400
  不带 --model    → 同样的 400   ← 账号默认也逃不掉
把环境变量拿掉,同一条命令返回 OK,花 $0.035。
```

⚠️ **所以变量不是「被忽略」——CLI 会转发上去,是 API 那头拒绝。**
今天把选择器放出去 = **每次运行都失败**。这就是 §2.2 给 codex 模型定的规矩:**宁可不给选**。

**落地状态:管道全通、有 Rust 测试,界面开关关着。**
`EngineBar.tsx` 的 `EFFORT_PICKER_ENABLED = false`,**一行就能开回来**。
修在 CLI 那边:effort 要 Opus 4.5+ / Sonnet 4.6+,这一版把 `sonnet`/`opus` 映射到更老的快照。
**`claude` 升级之后重测一次**,是这条唯一要做的事。

### 2.2 ⚠️ 顺手测出来的独立 bug:模型选择器里的 `opus` 是坏的

```
claude -p "…" --model opus
  → API Error: 404 "model: claude-opus-4-1-20250805"
```

这跟 effort 无关。**右侧栏的模型选择器现在提供 opus/sonnet/haiku,选 opus 会直接失败。**
之前没人测过。要么删掉 opus,要么等 CLI 升级 —— **这一窗没动,留给下一窗决定**。

### 2.3 ✅ 四个动作都跑通了,质量可以

### 2.4 ⚠️ 去重的查重器只认「几乎一模一样」,不认「换句话说同一件事」

第一版测试库我塞的全是**同义改写**(同一个事实用不同措辞写了 4 遍),
结果去重如实报告「疑似重复(0)」—— **不是它坏,是检测口径就是字符三元组 Jaccard ≥ 0.6**。
加了一对**几乎逐字相同**的块之后,它立刻报出 0.83 的相似度。

**这条对下一窗有两个意思:**
1. 测试库两种重复都放了,别再删掉那一对逐字的(`seed-workbench-lab.sh` 里写了原因);
2. 「换句话说的重复」正是 `DESIGN_CONTEXT_HYGIENE` §3.1 取代关系要治的病,

### 6.2 实机验 MCP(stdio 喂 JSON-RPC)

### 6.2-quater ⚠️ 探子进程可以不花模型额度(但有边界)

- **`--strict-config`(codex)**:把「要试的键」和「一个肯定不存在的键」一起传,
  报错只提假键 = 要试的键是真的。⚠️ 它验的是**键**,**不验值**。
- **拿包装脚本当探针**:把 MCP 服务器的 command 指向一个「记 argv/env 再 exec 真二进制」的脚本。
- **翻二进制里的字符串**:能证明「这个词在里面」,**不能证明「它现在还有效」**。
  ⚠️ **08-07 晚这条又被证实了一次,而且更狠**:effort 的解析器**确实在二进制里**,
  代码路径**确实会走到**,然后**API 拒绝**。翻字符串连「CLI 会不会转发它」都答不了。
- **`--help` 是一手资料**,但**它没写的东西不等于不存在**(effort 就没在 `--help` 里)。
