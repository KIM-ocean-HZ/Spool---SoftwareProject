# 设计稿 — 应用 EN 排版审计(2026-07-29,静态部分)

> 背景:Ocean 2026-07-29——"优化英文的字体大小排版等设计,这一套 UI 体系
> 最早是中文开发留下的"。本稿是**静态代码审计**的发现与整改计划;
> 视觉走查需要真机 EN 环境(隔离流程),与 EN 截图重摄同批做。

## 静态审计发现(按可信度排序)

1. **EN 文案超长溢出是最大风险**(中文 2–4 字的位置,EN 常要 8–15 字符):
   高危面:侧栏「捕捉中 ●」pill("Capturing ●")、头部「捕捉到此」幽灵钮、
   设置四 tab 标签、排序菜单项、pack 弹窗的意图/范围 pill 组。
   需真机逐面确认是否截断/换行/挤压。
2. **微字号的光学差**:`text-xs`(12px)在组件里有 94 处,`text-[10.5px]` 2 处
   (侧栏「最近/聚焦」区标)。同字号下拉丁字形光学上比汉字小——中文 12px 可读,
   EN 12px 偏密。候选:EN 下区标类微字号 +0.5–1px,或小型大写(uppercase +
   tracking)化——后者更像 VSCode 的区标语法,倾向后者。
3. **tracking 的语言差**:`tracking-wide` 配中文无感,配 EN 小写偏散;
   若走小型大写方案则 tracking-wide 恰好合适——与 #2 一并定。
4. **无问题面(已确认)**:字体栈(Geist 拉丁本就是主字体,PingFang 只是中文兜底)、
   日期/时间已走 `dateLocale()` 本地化、Fraunces 标题在 EN 下成立
   (官网已用同一套字体体系验证过观感)。

## 整改计划(待 Ocean 批复后执行)

2. 修复原则:**不做双语两套字号体系**——只修实际溢出 + 区标微字号一处决策
   (#2/#3 二选一),改动最小面。
3. 顺手产出:EN 界面截图一套,替换官网与 README 截图(RELEASE.md §3 本来

4. i18n 规则不变:中文即键;本次不新增文案,只动样式。

### 一、区标方案:选 A,已落地

`RecentSection.tsx` / `FocusSection.tsx` 两处区标在 `language === 'en'` 时加
`uppercase`,`tracking-wide` 保留,**字号不动**(仍 10.5px)。理由:大写拉丁的
字高由 cap height 主导,同字号下观感比小写大一档,#2 的「EN 偏密」和 #3 的
「tracking 配小写偏散」被同一处改动一起解决,不必再动字号(A 与 B 不叠加)。
中文分支完全不变。基线:`npx tsc -b` 通过,`npx vitest run` 152 全绿。

**仍欠视觉确认**:这是静态改动,EN 下的实际观感要在真机 EN 环境看一眼——
与下面的 EN 截图走查同批做,别单独为它开一次隔离构建。

### 二、官网/README 换 EN 截图:**不换**,改为「按语言各一套」并推迟

原提案(全站换成 EN 截图)会把割裂**镜像**到中文访客身上:官网是双语的
(`?lang=zh|en` 直链),截图却是单语资产,换成 EN 只是把「EN 文案配中文截图」
变成「中文文案配 EN 截图」,净收益接近零。正确终局是**每种语言各一套截图,
跟着现有 lang 切换换 src**;这次不做,理由三条:

1. **有前置问题未决**:产品默认语言是 `zh`(settingsStore `language: 'zh'`,
   §18 rule 11),且**内置教程脉络只有中文一版**(2026-07-30 干净安装冒烟测试
   实测:新库种出的三条脉络全中文,UI 首启也是中文)。英文用户下载后第一眼
   看到的是中文界面——那么「官网放 EN 截图」反而**不如**中文截图诚实。
   要不要让默认语言跟随系统 locale、教程要不要出 EN 版,是这件事的上游决策,
   得先定。
2. **成本不是样式级**:EN 截图要的不只是切语言,还要一套**英文演示库内容**
   (现有 `scripts/seed-demo-library.sh` 种的是中文),再走一遍隔离构建 +
   六面重摄 + 站点/README 资产替换与 alt 文案。这是内容 + 拍摄任务,不该
   混在排版整改里。
3. **RELEASE.md §3 的「截图与当前 UI 一致」现在是满足的**——当前默认 UI 就是
   中文,中文截图即一致。换成 EN 反而与默认首启不一致。

**下一步(等上游决策后)**:先定「默认语言是否跟随系统 + 教程是否出 EN 版」,
再一次性做:EN 演示库 → 隔离 EN 构建 → 五面走查(主窗口/设置四 tab/pack 弹窗/
捕捉浮层/收集面板,顺带确认本次区标观感)→ 双语截图各一套 → 站点按 lang 切换。
