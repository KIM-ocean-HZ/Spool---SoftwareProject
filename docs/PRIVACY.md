# Spool（思簿）隐私政策

最后更新：2026-07-06

## 一句话版本

**你的数据留在你的电脑上。** Spool 是本地优先的软件：捕捉、整理、打包、搜索全部在本机完成，不注册账号、不上传数据、不做遥测。只有当你主动配置并使用在线 AI 功能时，相关内容才会发送到你选择的 AI 服务商。

## 我们收集什么

**什么都不收集。** Spool 没有服务器。没有账号系统、没有使用统计、没有崩溃上报、没有广告标识符。开发者无法看到你的任何内容。

## 数据存放在哪里

- 所有内容（工作区、脉络、信息块、批注、附件索引）存放在本机的 SQLite 数据库：
  `~/Library/Application Support/com.oceanjin.spool/spool.db`
- 设置（含 API Key）存放在同目录的 `settings.json`。
- 附件本身不复制、不上传——Spool 只保存指向原文件的路径，以及（可选的）本地提取的文字内容。
- 数据库结构升级前会在同目录自动留存一份快照备份。

删除以上目录即可彻底清除 Spool 的全部数据；应用内「设置 → 清除所有数据」亦可。

## 什么时候会有数据离开你的电脑

仅在以下**你主动开启**的场景：

| 功能 | 发送内容 | 接收方 |
|---|---|---|
| 脉络状态摘要 / 结论摘要 | 该脉络的信息块文本（含已开启「加入 Pack」的附件提取文字） | 你配置的 Groq / Google Gemini / 本地 Ollama |
| 捕捉自动归类建议 | 新捕捉的文本 + 各脉络标题与近期片段 | 同上 |
| 图片文字提取（默认关闭） | 你附加的图片文件 | Google Gemini |
| MCP 服务（默认关闭） | 你的 AI 客户端主动拉取的脉络打包文本 | 你自己配置的本机 AI 客户端（Claude、Cursor 等） |

要点：

- **不配置 API Key，以上功能完全不可用，也就没有任何出网请求。**
- **隐私模式**开启后，云端 AI 入口全部隐藏，只允许本地 Ollama（数据不出机）。
- 打包（Pack）、搜索、捕捉是纯本地操作，任何情况下都不联网。
- 请注意：免费档的第三方 AI 服务（如 Gemini 免费层）可能将提交内容用于模型训练，属各服务商政策，与 Spool 无关；对此敏感请使用本地 Ollama 或不开启 AI。

## 系统权限说明

| 权限 | 用途 | 拒绝的后果 |
|---|---|---|
| 输入监听（双击 ⌥ 捕捉） | 识别 Option 键的双击/长按手势 | 仍可用 ⌘⇧C 捕捉 |
| 自动化（浏览器） | 读取当前标签页标题作为来源标注 | 来源退化为应用名 |
| 剪贴板 | 捕捉时读取剪贴板文本 | 无法捕捉 |

所有权限只在对应功能触发时使用，不做后台监控；剪贴板只在你按下捕捉快捷键的那一刻读取一次。
