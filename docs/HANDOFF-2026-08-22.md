**D-k 的原话**：「禁用当前快捷键，放在**设置**里和**系统顶部菜单栏的 Spool icon** 里
（方便在其他 app 里禁用快捷键）。这样能够防止使用其他带有 option 快捷键的 app 被 spool 抢占。」

⭐ **菜单栏那个入口是重点** —— 真实场景是人正在别的 app 里被抢，
让他先切回 Spool 主窗翻设置页，等于没做。

⚠️ **D-k 动手前必读工作计划 §2.D-k**，那里有两条一错就把功能做反的：
① 暂停时 `on_event` **必须放行事件（`return true`）**，返回 `false` 是删事件 —— 那正是要禁的行为；
② 别和已有的「系统把 tap 关了」那条自愈路径混在一起，否则自愈会去"修好"一个用户故意关掉的开关。

⚠️ **挡在发版前面的 B0 还在**：官网和 README 有**十处**「Spool 不需要 key / 永不联网」的说法，
压缩 sidecar 一发出去就变成假话。⛔ 它挡的是 B 批，**不挡 D 批**，位置和改法在工作计划 §1.B。
