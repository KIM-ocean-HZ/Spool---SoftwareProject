## 1. 一句话结论

**Spool 不是笔记软件，不是第二大脑，也不是 MCP 工具。**
它值得占的位置是：

> **跨 AI 的项目记忆 —— 由你挑选，存在你自己的机器上，交出去的每一个字你都看得见。**

三个定语缺一不可。少了「由你挑选」，它是 Pieces；少了「你自己的机器」，它是 ChatGPT
Projects；**少了「你都看得见」，它就是市面上任何一个记忆层** —— 而第三个定语，恰恰是
现在最没人讲、Spool 又天生具备的那一个。

## 2. 先把生意的现实摆平：这门生意现在是什么生意

在讨论文案之前，得先承认网站在为什么服务。查了发行状态之后，事实是这样的：

| 事实 | 出处 | 对网站的含义 |
|---|---|---|
| 免费、无账号、无遥测 | `PRIVACY.md` | **没有收入漏斗可做**，网站不是销售页 |
| 只有 `Spool-macOS-arm64.dmg` 一个资产 | `RELEASE.md` §2、台账 §1.2 | 受众上限被硬卡在 **Apple 芯片 Mac** |
| 没有自动更新 | `README.md` Status | 用户装完就失联，**只有网站能召回他** |
| 没有 LICENSE，保留所有权利 | `README.md`、memory `no-license-file` | **不许写「开源」** |
| 没有做过任何外部用户研究 | `CASE_STUDY_PAGE.md` §1 | 定位还是假设，**网站是第一个验证工具** |

所以官网的 KPI 只有三个，按重要性排：

1. **装机**（下载点击 → GitHub Release 下载数）
2. **可信**（一个陌生人能不能在 90 秒里相信「这东西不偷我的东西、也不是玩具」）
3. **验证定位**（他到底是被哪一屏说服的 —— 这决定第二版怎么改）

⚠️ **收入不在里面，现在也不该在里面**（展开见 §11）。

## 3. 市场地形：五个位置，四个已经被占了

（下面对竞品的判断来自我的常识，**发布前要现场核一遍**，别把没核过的话写进官网。）

| 类别 | 代表 | 他们占住的那个词 | 为什么打不过 / 打得过 |
|---|---|---|---|
| AI 笔记 / 知识库 | Notion、Capacities、Obsidian+插件 | 「你的写作和整理的家」 | **打不过，也不用打**。Spool 在他们**上游**：接住还不值得归档的碎片 |
| 自动记录型记忆层 | Pieces、Rewind 一类 | 「什么都替你记住」 | **不比记得多，比记得干净**。他们的代价是监视感、噪音、耗电 |
| 模型厂自带记忆 | ChatGPT Projects、Claude Projects | 「在我这儿你不用重讲」 | **免费、零安装、体验最好** —— 但**只在他们家里成立**，而且是黑盒 |
| 稍后读 / 高亮 | Readwise、mymind | 「你读过的东西不会丢」 | 面向**消费**，不面向**推进一件事** |
| 开发者上下文工具 | 各类 repo 上下文 / prompt 管理 | 「把代码库喂给模型」 | 只服务写代码，不服务申请季、论文、找工作 |

**还空着的那一格**：
把上面第 3 类的「不用重讲」，从**某一家 AI 的内部特权**，变成**用户自己带着走的资产**，
并且**是一份人能读的纯文本**。

这一格空着不是偶然 —— **模型厂结构上不会去占它**（占了等于承认上下文该带去竞品家），
**自动记录型也不会**（他们的卖点就是「你别管、我全记」，跟「你挑」正相反）。

## 4. 最值得讲的六件，按我的排序

排序标准是**「陌生人看完这一句，会不会去点下载」**，不是「工程上多难」。
第 3、4、6 三件是我认为**被自己人低估最多的**。

### ① 不用再从头向 AI 解释一遍项目
最直接的痛，人人有感。Capture / 时间线 / Pack 都只是手段，卖的是**项目的连续性**。
⭐ 而且这个承诺**可以量化**，`CASE_STUDY_PAGE.md` §1 自己写了：
**「重新进入一个项目应该花一次粘贴，而不是十分钟考古。」** —— **把这句原样搬上首页**。
具体的数字承诺转化率远高于形容词。

### ② 这份记忆不属于任何一家 AI
今天用 Claude、明天换 Codex、后天换一个还没出生的模型，项目不用重建。
⚠️ 这一条**单独说会被 ChatGPT Projects 抵消**（人家也说「不用重讲」），
所以它必须和 ③ 捆在一句里讲，否则是在替对手打广告。

### ③ ⭐ 交出去的是一份**你能逐字读**的简报 —— 我认为这是第一护城河
Pack 是**纯字符串拼装、不过模型、同一天同一个项目打出同样的字节**（台账 §1.1
有跨语言 golden 测试钉着）。它的商业含义比工程含义大得多：

- **可检查**：AI 答错的时候，你能看见它到底被喂了什么。所有「记忆」产品在这里都是黑盒。
- **可携带**：一段 Markdown，能粘给任何 AI、粘进邮件、粘进文档。**产品的成品不依赖产品**。
- **不会慢性失灵**：不花钱、不掉线、不会在你最需要的那天表现得不一样。

一句话上首页：**「AI 读到了什么，你自己看得见。」**
⚠️ 这句话 Pieces 不能说，ChatGPT Projects 不能说，Notion AI 也不能说。

### ④ ⭐ 捕捉的那三秒，收下的不只是那段话，还有**你当时为什么存它**
overlay 弹出来时**光标已经在批注框里**（memory `capture-note-first`）。
剪藏工具收的是**内容**；Spool 收的是**内容 + 你的判断**。
半年后你自己也想不起来当时为什么存 —— 而那句话恰恰是唯一没法事后补的东西。

⭐ 这是全站**最适合做演示的三秒**，也是**没有任何竞品有的一个动作**。
它还顺手喂饱了 ⑤：用户自己写的字，正是 pack 里权重最高的那一档。

### ⑤ 来源还是来源，你的判断还是你的判断
pack 开头把内容分四档，**明写让接收方怎么对待每一档**（`templates.ts` + golden fixture）：
📖 Reference 是事实底线 / 🧩 Synthesis 是别人的框架不是事实 / 🔄 Process 只读你反复卡在哪 /
💭 Personal 是**你自己的判断，权重最高，错了也要直说**。

⭐ **商业上要讲的不是「分了四档」，是最后那一档**：
**「在这份简报里，你的判断排在所有 AI 的综合之上。」**
平台方永远不会这么写 —— 那等于承认自己的输出不如用户。这是结构性的、抄不走的。

配套的三条硬规矩（一句话带过就够，别展开成规格说明）：
AI 写进来的必须署名、只能追加、**改不动你写的一个字**；作废与更正是显式关系，不是偷偷更新。

### ⑥ ⭐ 诚实本身是这个受众的转化器
`CASE_STUDY_LEDGER.md` 里有 **41 条失败复盘**：删过一次真库、一个做完了但根本不工作的
功能被留着并关掉、一次联网跟进花了 $0.45、以及白纸黑字的「**我们没做过任何用户研究**」。

对研究生、研究者、独立开发者这批人，**这比任何功能列表都好使**。愿意公开写「我把自己的
数据库删过一次，这是那天长出来的六道防线」的人，做的本地软件才敢装。

⚠️ **但它不上首页。** 首页放一个入口：**「它是怎么做出来的，以及什么坏过」**。
一次点击可达，不是埋在页脚。

## 5. 什么最能促成下载：一个承诺 + 三个证据 + 一条边界

我不主张「痛点—功能—信任」那套常规排法。对这个产品，转化链条是这样的：

```
一个承诺   →  换个 AI 也不用重讲            （谁都会说，所以只值 5 秒）
证据一     →  三秒钟存下内容 + 你的判断      （只有你有，看得见）
证据二     →  一份你读得懂的简报（真的 pack）（黑盒 vs 明文，差异在这儿）
证据三     →  粘进另一个 AI，它接着往下说    （承诺兑现的那一帧）
一条边界   →  它不做什么、什么会离开这台 Mac （诚实换信任，顺手拦掉退货）
```

⭐ **「一条边界」是转化项，不是免责声明。** 提前说清 Apple 芯片、没有自动更新、
不是团队工具、没有 iOS —— 这批用户会**因为你先说**而更愿意装。

⚠️ **最后一屏必须能被截图传播。** 现实的获客渠道不是 SEO，是有人把一张图丢进群里 /
发条帖子。所以首屏要在 600px 宽度下**一眼读完一句话 + 看懂一张图**。
现在这一条是硬约束，会反过来决定首屏能放多少字。

## 6. 首页结构提案

```
1  首屏      一句承诺 + 真实产品画面 + 下载（写明 Apple 芯片）
2  为什么难  你的项目横跨浏览器/邮箱/两三个 AI，而每一场新对话都从零开始
3  证据一    三秒：存内容，也存你当时的判断        ← 真机截图 + 极短动图
4  证据二    交出去的是这份东西（真的 pack 明文）  ← 全站最重要的一张图
5  证据三    换一个 AI，接着上次那句往下说
6  它凭什么可信  本机 / 无账号 / 无遥测 / AI 只能追加不能改你写的字 / 签名公证
7  想更省事（可折叠）  MCP：让 AI 自己去取，不用你粘
8  它不做什么  Apple 芯片 · 无自动更新 · 不是团队工具 · 不是 Notion 替代
9  它是怎么做出来的  → case study 页
10 下载
```

**只有 10 屏，而且第 7 屏是折起来的。** 三条理由：

- **MCP 放在第 7 屏、而且默认折叠，是刻意的。** 不只是「太长」的问题 ——
  ⭐ **首屏讲 MCP，转化来的是爱折腾的人**，他手上有四个同类工具，装完就走；
  **首屏讲「不用重讲」，转化来的是真有项目问题的人**，他会留下。
  MCP 会放大错误的买家。
- 第 4 屏（真 pack 明文）**是全站唯一一张别人抄不走的图**，位置要靠前。
- 第 8 屏（不做什么）放在下载前一屏，是**为了让下载的人不后悔**。

## 8. 视觉与演示

- **奶油纸 / 墨色 / 克制的琥珀继续用。** 别做成黑底霓虹粒子那种「AI 官网」——
  这个产品卖的是安静和可信，视觉就是论据的一部分。
- ⚠️⚠️ **图必须是真机截图，不许效果图**（memory `mockups-vs-installing`：Ocean 原话
  「渲染的图示和真实不一样」）。而 `CASE_STUDY_PAGE.md` 自己写着现有截图**已经过期**
  —— 所以「重拍」是上线的前置条件，不是美化项。
- **截图按「一个完整场景」拍，不按「一个组件」拍。** 用户买的是流程，不是控件。
- 演示只做**三步**：存 → 打包 → 粘进另一个 AI。
  再多的步骤（MCP、待审、跟进）挪到折叠区，或者干脆放进 case study。
- 动画只在滚到那一段时才动，**要支持 `prefers-reduced-motion`**。
- ⭐ 一根琥珀色的线贯穿全页（线从一个应用被收进线轴、再放给另一个 AI）——
  产品名字就是线轴，App 里那个线轴组件已经是这个隐喻了，官网接上它是免费的一致性。

## 10. 怎么验证：网站是唯一的测量点

app 零遥测**不动**。测量只发生在网站上，而且要测得干净（无 cookie、不落个人数据，
**并且在页面上说一句**，否则隐私叙事自伤）。

**三个数**
1. 下载按钮点击（匿名）
2. GitHub Release 的下载数
3. **点下载时人在第几屏**（滚动分桶就够）

**一个定性问题**，放在**下载之后**而不是之前：
> 「你现在同时在用几个 AI？」

**判读规则（这条比数字本身重要）**
- 多数人在**第 1 屏**就下载 → **承诺够强**，第二版继续压缩篇幅。
- 多数人滚到**第 4 屏（真 pack 那张）**才下载 → **差异点才是买点**，第二版把它提到第 2 屏。
- 大量到第 7 屏（MCP）才下载 → ⚠️ 警报：**转化来的是爱折腾的人**，定位需要重新想。

这正好回答 §2 里那个「定位还没被外部验证过」的方法论缺口 ——
**网站是第一次有非作者本人的人来投票。**

## 11. 商业化：现在别做什么，将来能做什么

**现在不收费，理由是结构性的**：收费需要账号、服务器、遥测中的至少一样，
而这三样**每一样都动隐私叙事的红线**。为了收第一笔钱去动那条线，是拿护城河换零钱。

**将来的三条路，按与红线的冲突程度从小到大**：

| 路 | 冲突 | 说明 |
|---|---|---|
| **一次性买断的配套**（例如 iOS 捕捉端） | 小 | 不需要服务器；买断而非订阅，和「东西是你的」这套话一致 |
| **赞助 / GitHub Sponsors** | 无 | 配 case study 页效果最好 —— 那页卖的就是「这个人靠谱」 |
| **端到端加密同步** | **大** | 必须有服务器。**要 Ocean 明示改叙事才能做**，不能顺手做 |

⛔ **绝不能关进付费墙的三样**：Pack、来源分级、MCP。
它们就是口碑循环本身，收了它们等于把获客渠道自己掐了。

⭐ **LICENSE 悬而未决不是遗漏，是留着的商业选项**（`CASE_STUDY_PAGE.md` §8 已经写明
「一扇单向门」）。网站现在**不必谈许可**，只要别说「开源」。

## 12. 我认为最容易被外部评审漏掉的三点

（写在这里，方便和 GPT 那份逐条对。）

1. **「可读、可检查的成品」没有被当成第一护城河。**
   多数评审会把 pack 讲成「一键打包」这个动作，而它真正稀缺的是**输出是明文、可核对、
   不依赖 Spool 存在**。⭐ 顺带一个反直觉的结论：**产品的成品不依赖产品，反而是卖点** ——
   它让「装一个小众 App」这件事的风险降到零。

2. **捕捉那三秒收下的是「为什么」，不是内容。**
   它常被写成「Save / 保存」这类弱动词，但这是**唯一一个竞品完全没有的动作**，
   也是 ⑤ 那个「你的判断权重最高」的**供料口** —— 两件事其实是一件事，
   分开讲会把两边都讲弱。

3. **诚实（41 条失败复盘 + 「我们没做过用户研究」）是资产，不是风险。**
   对研究生 / 研究者 / 独立开发者这批人，它比功能列表更能促成安装。
   ⚠️ 但位置要对：**一次点击可达，不上首页**。
