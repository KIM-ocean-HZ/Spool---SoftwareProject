## 2. 重做方案

### 2.1 定位不变(08-02 那三条继续管着这一版)

1. **卖那个每天都在发生的痛**(每开一个新对话就要重讲一遍项目),不卖「记东西的地方」。
2. **首页只写给「长期做一件事」的人** —— AI 重度用户、开发者、学生和做学术的。
   找工作、签证这类短期事务**不作为首页场景**。
3. **别花版面强调「简单易学」**,版面留给信任信息和 FAQ。
4. 文案**大白话**(硬规则 4),中文是**重写不是翻译**。
5. 不许有任何暗示第三方背书的话、编造的用户数、评价、媒体报道。

### 2.2 ⭐ 这一版真正的变化:故事从「一条管子」变成「一个有闸门的环」

| | 上一版官网讲的 | 这一版要讲的 |
|---|---|---|
| 形状 | 存 → 攒 → 粘出去(**单向**) | 存 → 攒 → **递出去 / AI 自己伸手进来拿**,它写回来的东西**先停在你这道闸前** |
| AI 的位置 | 一个你粘贴的对象 | 一个能读能写、但**必须署名、只能追加、写回来要你点头**的角色 |
| 新说的一件事 | — | **它还会替你盯着**(跟进 + 周回顾),而且**没新东西就不出声** |

⚠️ **这不是「加功能列表」。** 一段只讲一件事,每件事都用「你能得到什么」开口,
数字和工具名一律不出现(旧稿 §4.6 定的规矩)。

### 2.5 ⚠️ 顺带发现:README 也有一处不准了

`README.md` 那张四个动作的表(Distill / Dedupe / Follow up / Weekly review)写的是
「Spool 能跑这四个」——**08-11 Ocean 已经把压缩和去重从 app 里撤了**(`HANDOFF §5-C`),
Spool 界面上现在只剩**跟进**和**周回顾**;压缩和去重仍然活在 MCP 那侧(给聊天客户端用)。
**这一处不在本稿范围内,留档给下一摊。**

### 2.6 交互小组件(demo.js)怎么重做 —— ⏳ 等他定故事线

现在那个 578 行的小组件本身是好的(四步、每步一句引导、按真键 ⌥⌥、断网可跑),
**要换的是里面的故事和它走到哪一步为止**:

- **故事**:从「找工作」换成一个**长期项目**。要他在两条里选一条(§3 第 2 题)。
- **走到哪**:现在是 存 → 打包 → 粘给新对话 → MCP 读。
  建议**加第五步**:AI 写回来 → **停在待审面** → 你点「收下」。
  理由:§2.2 那个「有闸门的环」是这一版的主张,而 demo 是唯一能让人**亲手点一下那道闸**的地方。
