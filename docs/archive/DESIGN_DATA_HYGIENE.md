## 3. `check_library` 接口与行为规则

**接口**(新只读工具,工具面 9 → 10):

```
check_library()        — 无参数,全库体检
```

**输出**:确定性拼装的 Markdown 报告,三节 + 头部计数摘要:

```
# Spool 库体检 — 2026-07-12
59 blocks / 14 threads scanned. Findings: source 卫生 1 · 正文裸 id 2 · 引用完整性 0。

## 1. Source 标签卫生(1)
- 〈MCP 实测 · 0709〉 · [2026-07-09 14:16] · 字段 source · 署名:AI(Claude (Cowork) · MCP)
  片段:「依据 spool://thread/sbC2zgToQ6yL7hBWxTjTg」→ 指向现存脉络〈Scheduling - Asynchronou…〉
  预览:Scheduling 复习卡片 ×3(按你 pack 中的真实薄弱点定制)…
  处置:在 Spool 中点击该块的来源标签即可编辑(Spool 不代改)。

## 2. 正文/批注裸 id(2)
(同款条目;用户手写命中时,处置行换为:「用户手写内容,仅供知悉,Spool 不建议也不会修改。」)

## 3. 引用完整性(0)
(命中时列出引用方块的预览与「被引块已不存在 / 所在脉络已删」;pack 侧已自动降级为
 "(cited block no longer exists)",此节只是让用户看得见。)

体检通过 / 未通过一行结语。
```

**行为规则(全部机械、可复述):**

1. **扫描范围**:非软删脉络的全部块(content / annotation / source 三字段)+
   threads.title / threads.summary + workspaces.title。软删脉络不扫(GUI 处置不可达)。
2. **检测器**,与写入面警告同源:
   - D-URI:字段含子串 `spool://`;
   - D-ID:复用 `suspect_raw_id`(21 位 nanoid 字符连串、双大小写、词边界);
   - D-REF:SQL——`ref_block_id` 非空且(被引块不存在 **或** 被引块所在脉络已软删)。
3. **署名家族**(机械判定,决定处置行措辞):`source LIKE '%· MCP%'` → AI,建议编辑;
   source 非空无 `· MCP` → 捕捉来源,「大概率为原文自带的 id 形状串,仅供知悉」;
   source 为空 → 用户手写,「仅供知悉,Spool 不建议也不会修改」(宪法 5)。
   threads.summary 按 `summary_source='mcp'` 判 AI;title/workspace 无署名,一律「仅供知悉」。
4. **可解析性标注**:命中的 id 若解析到现存脉络/块,附其标题(块附所在脉络标题 +
   预览);解析不到则标注「未指向现存对象」。
5. **排序**:节内按(脉络标题,created_at,rowid)升序;跨节固定 1→2→3。同库同输出,
   无时间窗依赖——确定性可测。
6. **预算**:每节至多 50 条,超出输出 `(+N more)`(现实库远小于此,仅是安全帽)。
7. **命名规则**:条目一律以脉络标题 + 时间 + 预览定位;**违规片段本身全文引用**——
   此处 id 是报告对象而非指称手段,与 add_block 的 raw_id_warning 同例(「」引号同款)。
8. **空态**:三节全 0 → 「体检通过:未发现内部管线泄漏或悬空引用。」

## 4. 合宪性

- **只读,零字节修改** → 宪法 5(用户内容神圣)天然满足;处置权完全在用户手里,
  连 AI 署名块也不代改——比迁移方案更强的保证。
- 判定规则全机械(子串 / 字符类 / 长度 / SQL EXISTS),零 AI 判断,规则在报告头部
  自我披露,模型和用户都能验算 → 宪法 4(确定性)。
- 报告引用违规片段:遵循既有先例(raw_id_warning 全文引用命中串);其余定位信息
  一律标题 + 预览,不引入新的 id 暴露面。

## 5. 顺带评估:GUI ref_block_id 最小可视化(P2-3)

建议**做最小版**,与体检解耦、独立提交:

- BlockItem 在批注行之后渲染一行安静的 `↩` 引用行,语义与 pack 完全一致:
  被引块在场 → `↩ [时间] 40 字符头锚点`(复用 assemble.ts 的 headAnchor 口径);
  悬空 → muted 的「引用的块已删除」。无按钮、无弹层、无跳转(§2.5 安静原则;
  跳转牵涉跨脉络导航,留待真实需要)。
- 成本极低:GUI Block 类型已带 `refBlockId`(v7 起),只差渲染 + 一次被引块批量
  解析(db 层已有 pack 用的解析函数可参照);i18n 新增约 2 词条(中 + EN)。
- 真库现有 3 行 live citation,实机隔离构建可直接对比验证。
