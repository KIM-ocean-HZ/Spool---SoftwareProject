## 1. 权限横幅(评审 #1,最高优)

现状:已授权本来就不渲染(`hidden`),没问题;问题在 **denied 态两行常驻**——
第二行 stale-grant 恢复指引(约 60 字)永远陈列。拟改:

- denied 收成单行:主句(截断)+「打开系统设置」+ **「详情」文字钮** + ×;
  点「详情」才展开恢复指引行(默认收起,§2.5)。
- granted-later 本来就单行,不动。× 仍是会话级 dismiss(权限缺失是功能残缺,
  每次启动提醒一次是合理的;不加持久化)。
- 成本:PermissionBanner.tsx 一处 + i18n 一键;无逻辑变更。

## 2. 设置信息架构(评审 #2)

拟改 tab 化:**通用 · MCP · 快捷键 · 高级**。

- 通用 = 语言 / 开机启动 / 附件提取;**MCP 独立成 tab 排第二**(产品核心,
  内容已经很厚:双开关 + 一键接入 + 使用提示 + 示例用法 + 手动 snippet);
  快捷键 = 现 ShortcutConfig;高级 = 浏览器自动化五行 + 清除所有数据。
- 现组件本就分文件(GeneralConfig / ShortcutConfig / BrowserAutomation),
  重组是搬运不是重写;GeneralConfig 拆出 MCP 段成独立组件。
- 成本:中(Settings/index.tsx tab 骨架 + 拆件 + i18n 4 词条);纯呈现层。
- 注意:设置滚动位置记忆行为随 tab 化自然消失(每 tab 内容变短,无需滚动记忆)。

## 3. ThreadHeader 密度(评审 #3)

拟改最小版:右上动作区只留**「打包」**(唯一显性动作),「完成项目」「捕捉目标」
(done 态的「重开」同理)收进 ⋯ overflow 菜单;状态 pill / 日期 / 字数的次级行
维持现状(它们已在标题下方一行,信息有效)。
成本:ThreadHeader.tsx 一处 + 一个轻量菜单(无新依赖);键盘/语义不变。

## 4. 低频控件(评审 #4)

- 块流右上「排序 按时间/按来源」→ 单图标钮(lucide ArrowUpDown),点击在两种模式
  间轮换,tooltip 显示当前模式;省出一整行视觉。
- 侧栏顶部统计行(N 进行中 · N 本周到期 · N 搁置):**删除**(SidebarSummary 组件
  连引用一起移除)。评审原话「信息价值低」;deadline 将至在脉络行上已有自己的信号。

## 5. 块卡片三重容器感(评审 #5)

A = 现状:圆角 + 边框 + 底色(bg-paper/40 + border-line/60)。
B = 无边框列表式:去边框去底色,块间以留白 + 细分隔线区隔,hover 时浮现操作行
(现有交互不变)+ 极轻 hover 底色;置顶的左侧 accent 条、选中/拖放 ring、flash
高亮全部保留语义只适配样式。

**建议先做 B 的隔离构建,与 A 并排截图交 Ocean 再定**——这是六项里唯一动整体
气质的,不适合文字定案。

## 6. 小一致性(评审 #6)

1. 日期 pill:native `<input type="date">` 的显示格式跟系统 locale(所以是美式)。
   拟改:非编辑态渲染 ISO 文本(2026-07-12),点击才切换成 input 编辑——与 pack
   的 ISO 口径一致。
2. 两处 × 关闭钮(权限横幅字符 × vs 设置 lucide X)统一为 lucide X,muted → hover ink。
3. 空状态文案分层:主句(serif 斜体)不动,操作提示拆行并降为 text-muted 小字。
