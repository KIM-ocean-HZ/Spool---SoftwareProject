## 4. ⛔ 下次做连夜实测之前必读（这一夜最贵的教训）

**钥匙串 ACL 按二进制认，`cargo test` 重编一次就要重新授权一次。**
而**授权框在锁屏状态下弹不出来**，`SecItemCopyMatching` 会**无限期阻塞**。

三种表现，⛔ 别混：

| 空计划耗时 | 什么意思 |
|---|---|
| **~0.8s** | 已授权过，正常 |
| **~10–75s，屏幕上没有框** | 刚重编过，系统在重新验签。⭐ **正常，等着就好** |
| **几百秒过不去** | ⛔ **屏幕锁了** |

**怎么确认**（几秒钟，不弹框）：
```bash
ioreg -n Root -d1 -r | grep -o 'CGSSessionScreenIsLocked[^,]*'   # = Yes 就是它
```

⭐ **下一轮的做法**：**跑之前一次性把代码改完、编完，当着人的面跑一次空计划把授权拿到，
之后整夜一行 Rust 都不要再改。** 这一夜就是败在「跑到一半发现少一个旋钮」。
⛔ 交接里那句「始终允许跨重新编译仍然有效」**是错的**，已改。
（全稿在记忆 `isolated-verify-workflow` §35。）
