## 2. 一件事没照字面做，理由写在这儿

**「查找快捷键默认为 cmd F」这句，做成了「窗口里的 ⌘F」，⛔ 没有把系统级热键改成 ⌘F。**

Spool 的搜索快捷键（设置 → 快捷键那一行）是**系统级**的：在别的软件里按也算，
它的用处是「Spool 窗口没在前面时也能叫出来」。把它改成 ⌘F，等于把 ⌘F 从**每一个**
别的软件手里抢走 —— 浏览器、编辑器、Finder 里的查找全部失效。那正好撞上已经定过的
一条规矩：Spool 不许挤掉别的工具。

而「对齐其他软件」这件事本身，别的软件的 ⌘F 也是「窗口在前面才算」的。所以：

- 窗口在最前面 → **⌘F**（新加的，写死在窗口里，不占系统热键）。
- 窗口没在前面 → **⌘⇧F**（原样，设置里可改）。

设置 → 快捷键那一行的说明也改了，把这两件事都写出来了。

如果 Ocean 就是要连系统级那个也换成 ⌘F，那是一句话的事（`src/lib/capture/shortcut.ts`
的 `DEFAULT_SEARCH_ACCEL` + `src-tauri/src/capture.rs` 的 `search_accelerator`），
但代价就是上面这一段。⇒ 等他一句话。

## 4. 顺手修的一个旧毛病（不是这三件里的）

实机验收时看见的：在全局搜索面板里**按 ↵** 跳转，查找条挂出来了、命中也高亮了，
但**查找框是空的**，计数那一格也是空的。

根子：`SearchOverlay.navigate()` 先 `closeSearch()`（它会把 `query` 清空），再由
`useSearch` 的收尾 effect 去 `startNavigation(..., query)` —— 那时 `query` 已经没了。
点结果那条路没事，因为 `SearchResultItem` 在 close 之前就把 `query` 读走了。

修法一行：收尾时用 `query.trim() || navQuery`。`navQuery` 是同一句话的副本，本来就是
为「面板关掉之后还要用」留着的。

## 5. 怎么验（照着点，一步一动作）

装好之后打开任意一个块多一点的项目。

1. **字号**：设置（⌘,）→ 通用 → 「正文字号」→ 点「大」。块里的字变大，左边侧边栏、
   时间、来源那些小字**不变**。再点「小」，块里的字变小，别处照样不变。点回「中」，
   应当和换装之前一模一样。
2. **⌘F**：随便在一块正文里用鼠标划中一个词，按 ⌘F。搜索框弹出来，里面已经是那个词、
   而且是选中状态。直接按 ↵ —— 跳到第一条命中，上面挂出查找条，**框里是那个词**，
   右边显示「1 / N」。
3. **查找条不会自己没了**：在正文里随便点几下，翻几页。查找条一直在。按 ✕ 或 Esc 才关。
4. **那张列表**：点查找条上的「≡ 数字」。列表弹出来，背景是实的，底下的正文透不上来。
   点其中一条，跳到那一块。
5. **右侧刻度**：查找开着的时候看右边那一列刻度 —— 带这个词的那几块，刻度是橙色的、
   而且比别的长。鼠标停在其中一根上，出来一张卡，写着「第 N / M 块」+「查找命中」，
   下面是**对上的那一行**。点一下，跳到那一块，命中高亮着。
