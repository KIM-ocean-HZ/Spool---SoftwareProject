## 2. ⓪ 那件的证据（这一件你只需要看这一节）

**结论：不是「猜是 X」，是量出来的。**

Spool 和后台之间每说一句话（读钥匙串、查前台是哪个 app、看一个文件在不在……）都要调一个「命令」。
这些命令**默认跑在画界面的那条线上**。所以只要有一个命令卡住，整个 Spool 就冻住 —— 打不了字、
点不动、动画停住 —— 而别的软件一切正常，等它自己回来。这和你说的一模一样。

怎么证的：写了一个哨兵，每 0.2 秒问一次主线程「你还在吗」，然后做了一次对照实验：

```
同一段活儿，占 3 秒：
  普通命令      → 主线程冻了 3001 毫秒（哨兵连报 13 次）
  加了 async 的 →  一次都没报
```

另外，在**还没修**的那一版上，抓到过一次**自发的、9 秒**的主线程冻结（开机后半分钟左右）。

**修法**：把十条「会做慢活儿」的命令搬下主线程。最要命的是读钥匙串那三条 —— 这个仓库自己
量过：二进制重新签名之后，第一次读钥匙串要 **60–75 秒**；屏幕锁着的时候干脆**无限期**卡住。
你 08-27 上午刚换过装（= 新的签名），下午就撞上假死，时间对得上。

⚠️ **一句实话**：我没能指认「你那三十秒具体是哪一条命令」——它当时没在探针底下发生。
我做的是把**整类**可能性从主线程上拿掉了。如果换装之后还再出现一次，那说明还有一条漏网的，
到时候把当时的时间点告诉我，探针可以再装回去。

⚠️ 另外两个疑点已经排除：
- **pdfjs 抽 PDF 正文**：它跑在一个独立的 worker 线程里，卡不到界面。
- **双击 ⌥ 那个键盘钩子**：所有运行里一次「tap 被系统关掉」的日志都没有；而且它真卡的话，
  是**所有** app 一起卡，和「只有 Spool」对不上。

## 3. 三处没照字面做（都要你点头或者知情）

**一、⑨ 上面那行字写的是「已专注 N 分钟」，不是「今天已专注 N 分钟」。**
你选的是「本次开机以来累计、不落盘」这一档，那么「今天」这两个字在两种情况下是假的：
下午三点重开一次 Spool（今天的前半天没算进去）、开着跨过午夜（昨天的算进今天了）。
代码里那条老注释说的正是这件事——「重启之后还显示『你已经工作了 47 分钟』是在替用户撒谎」。
⇒ 要写「今天」，就得落盘按天算（你当时的乙档），说一声就改。

**二、③ 的双击**没有跟着长按一起等 450 毫秒。
你的原话是「先等够长按阈值再决定是哪一种」。照字面做，每一次双击捕捉都要先卡半秒才弹窗，
而捕捉这条路是有硬指标的（按键到浮窗 200 毫秒内）。
⇒ 改成：双击照旧立刻响；长按是一个**可以被取消的定时器** —— 这半秒里只要发生了别的事
（松开、又按一次、双击已经触发、按了别的键、点了鼠标），长按就作废。
两条永远只有一条会响，而双击一毫秒都没慢。

**三、⑥ 那个虚线框的字原来是错的，我改了。**
它写着「松开以新建一个块」，但从访达拖文件进来**不会新建块** —— 文件是加进这个项目的
文件清单的（这是很早以前改过的行为，这句文案是那次漏下的）。这也正是你不知道它是干什么的原因。
⇒ 现在写的是「**松开，把文件加进这个项目**」。你选的就是这一条。

## 5. 怎么验（照着点，一步一动作）

打开任意一个块比较多的项目。

**④ 会丢字那件（最要紧，先验这个）**
1. 在最下面的输入框里打几个字，**别按 Enter**。
2. 按 ⌘F，随便搜一个别的项目里才有的词，按 ↵ 跳过去。
3. 点回刚才那个项目。→ **输入框里的字应该还在。**

**② 搜索计数**
1. ⌘F 搜一个常见词，↵ 跳过去。
2. 看查找条上那一行：应该写着「这一块 第 1 / N 处」「本项目 X 处 · Y 块」「全部 M 处 · K 块」。
   三个数说的是三件不同的事，⛔ 不该再需要猜。

**⑤ 结果不再是空白**
1. ⌘F 搜一个词。
2. 看弹出来那张单子：**每一条的第一行都该有字**，⛔ 不该先出现一条空白再往下看。

**① 刻度旁边的小 block 预览**
1. 查找开着的时候，把鼠标移到窗口最右边那一列刻度上。
2. 左边滑出一列小方块：中间那个是你现在这一块（描边是橙的），上下是这个项目里别的命中，
   **越往外越小**。
3. 点其中一个 → 跳到那一块。鼠标移开 → 收回去，刻度还是原来那么细。

**⑥ 虚线框**
1. 平时看着底下：**不该有那个虚线框**。
2. 从访达拖一个文件进来（先别松手）→ 框出现，写着「松开，把文件加进这个项目」。
3. 把文件拖出窗口外面松手（取消这次拖拽）→ **框应该在一秒内自己消失**（这就是原来那个毛病）。

**⑦ 发完滚过去**
1. 在一个块很多的项目里，先滚到最上面。
2. 在输入框写一条，按 Enter。→ 正文应该自动跟到刚写的那一条。

**⑧ 排版三档**
1. 双击一块（或点它右上角那支笔）打开编辑面板。
2. 顶上现在有「标题 / 正文 / 斜体」。把光标放在某一行，点「标题」→ 那一行变成标题；点「正文」→ 变回来。
3. 划中半句话点「斜体」→ 只有那半句变斜。点「完成」。
4. 再看一个**有两段话**的块：第一段**不该**再自动加粗。
5. 去设置里把正文字号切成「大」→ 标题也跟着变大，⛔ 不会乱。

**⑨ 专注时间**
1. 看侧边栏那张卡（它和「你捕捉了多少条」轮流出现，切走再切回来会换）。
2. 上面那行现在是「**已专注 N 分钟**」，下面是「N 分钟后歇一会儿」。
3. 到点休息之后，**上面那个数不会归零**，接着往上加。
   ⚠️ 这一步我没能在这一窗里当场看到（要等满一个完整的工作时长），代码里两个测试钉着它。

**③ 长按 ⌥（这一件必须你自己按，见 §6）**
1. 在任意一个软件里，**按住 ⌥ 大概半秒**再松开。
2. 屏幕右上角弹出和捕捉一样的浮窗，但正文是空的，光标已经在里面。
3. 直接打字，然后按 **⌘↵**（或点「完成」）。
4. 回 Spool 看当前捕捉项目 → 最下面多了刚写的那一条，**没有来源**（那一行是空的）。
5. 再试两件不该出事的：**双击 ⌥** 照旧是捕捉剪贴板；按住 ⌥ 再按别的键（比如 ⌥+方向键）
   **不该**弹出浮窗。
6. 把「暂停捕捉手势」打开（菜单栏 Spool 图标里）→ 长按 ⌥ 应该也一起停。

**⓪ 假死**
这一件没法「点一下就验」——它本来就是偶发的。⇒ **用一阵子**。再遇到一次就告诉我时间点。

## 7. 留给下一窗的（都不挡渠道）

1. **`withSpine` 那套机制现在没人用了。** 自动加粗的开关已经在产品里关掉（⑧），但
   `MarkdownContent` / `contentRuns` 里那条参数和它的几组测试还在。要不要一起清掉是另一件事
   —— 那会动到分词器，而分词器是「跳到命中处」的坐标系，⛔ 不该顺手做。
2. **④ 的草稿只在内存里**，重启 Spool 就没了。这一次修的是「切项目就没了」，不是「重启还在」。
   要跨重启留住，得先决定一条没发出去的草稿算不算库里的内容。
3. **⓪ 还有一条没指认的**：见 §2 最后那段实话。
4. **⑦ 有一次没跟过去**（合成输入那一轮），后来复现不了，探针显示每一步判断都是对的。
   怀疑是合成输入自己的抖动，也可能是平滑滚动被打断（用户自己滚动会打断它，那是对的行为）。
   ⇒ 记在这儿，真遇到再说。
5. **⑨ 想要「今天」而不是「本次开机」**，见 §3 第一条，一句话的事。
