# Windows 首版 —— 装机和验收（给 Ocean）

> 这份是给你在 Windows 电脑上照着做的。**一步一个动作**，
> 每条前面一个 ☐，做完打个勾；哪条不对，把那条的编号发给我就行。
>
> ⚠️ **这些代码一行都没有在真 Windows 上跑过。** GitHub 上的机器只证明了
> 「编译得过、单元测试是绿的、能打出安装包」。**它长什么样、点下去有没有反应，
> 只有你能看见。** 所以下面每一条都是真的在问，不是走过场。
>
> ⚠️ **Mac 那边一个字都没动。** 这些改动在一个叫 `windows-port` 的分支上，
> 没有合进 main。你 Mac 上的 Spool 该怎样还是怎样。

## 第一部分：拿到安装包

**你不需要在 Windows 上装任何开发工具。** 安装包是 GitHub 上的机器编译好的，
你只要下载。

☐ **1.** 在 Windows 上打开浏览器，登录 GitHub，进这个页面：

```
https://github.com/KIM-ocean-HZ/spool/actions
```

☐ **2.** 左边一列点 **「Windows build」**。

☐ **3.** 列表最上面那一条就是最新的。看它左边的图标：

- **绿色的勾** → 编译成功，往下走。
- **黄色的圈** → 还在编译，等几分钟刷新一下（第一次大概 15–25 分钟）。
- **红色的叉** → 编译失败了。**别往下走，把这一条的网址发给我。**

☐ **4.** 点进那一条，页面拉到最底下，有一块叫 **「Artifacts」**，
里面有一个 **`spool-windows-nsis`**。点它，会下载一个 zip。

☐ **5.** 解压那个 zip，里面是一个 **`.exe`** 文件，名字大概长这样：

```
Spool_0.4.0_x64-setup.exe
```

## 第二部分：装上去

⚠️ **这个安装包没有签名**（是你自己 08-15 定的：首版先不签名）。
所以 Windows 一定会拦一下。**这是预期的，不是坏了。**

☐ **6.** 双击那个 `.exe`。

☐ **7.** 如果出现一个蓝色的窗口写着 **「Windows 已保护你的电脑」**
（英文是 "Windows protected your PC"）：

1. 点那句话下面的 **「更多信息」**（"More info"）；
2. 下面会多出一个按钮 **「仍要运行」**（"Run anyway"）；点它。

☐ **8.** 之后就是普通的安装向导，一路下一步。
**不需要管理员密码** —— 它装在你自己的用户目录里。

☐ **9.** 装完打开 Spool。

**如果开不起来 / 白屏 / 报 WebView2 的错**：这个安装包安装时需要联网下载一个
叫 WebView2 的微软运行时。确认网是通的，然后重装一次。如果还是不行，
把报错的截图发我。

## 第三部分：验收 —— 先看这四件

这四件是你 08-15 定的首版范围（**能装能跑 + 快捷键捕捉 + 打包 + MCP 接得上**）。
**其他都可以先不管，这四件不过就是没做成。**

### A. 能装能跑

☐ **10.** 窗口开起来了，不是白屏。左边能看到侧边栏。

☐ **11.** 屏幕右下角任务栏那一排小图标里（可能要点那个 `∧` 展开），
**能看见 Spool 的图标**。
⚠️ **这条我特别不确定**：那张图标在 Mac 上是一张纯黑的图，
Windows 的托盘是深色的，黑图画上去就是看不见。我改成用彩色的 app 图标了，
但没人验过。**如果那里是空的、或者是一个黑方块，告诉我。**

☐ **12.** 右键那个托盘图标，能弹出菜单，里面有「退出」。

☐ **13.** 点窗口右上角的 ✕。**窗口应该只是藏起来，app 还在托盘里活着。**
再点一次托盘图标，窗口回来。

☐ **14.** 新建一个项目，写一条内容，按回车。它存下来了。

☐ **14b.** 打开首启自动建的那个「欢迎使用 Spool」项目，**看第 2 块**。
它应该说的是「先去设一个快捷键，然后 Ctrl+C 复制再按那个快捷键」。
⚠️ **如果它说的是「双击 ⌥（Option）」或者「打开输入监听权限」，告诉我** ——
那是 Mac 的说法，Windows 上照着做什么也不会发生。
（其他块里的 `⌘⇧P` 之类也应该显示成 `Ctrl+Shift+P`。）

### B. 快捷键捕捉

⚠️ **Windows 上没有「双击 ⌥」这种手势**（你 08-15 定的先不做）。
**首版也没有给默认快捷键**（你今天定的：装机时你现场试）。
所以第一次打开，捕捉是完全不能用的 —— 这是对的，不是 bug。

☐ **15.** 窗口最上面应该有一条横幅，大意是
**「想在别的 app 里复制就存，先给捕捉定一个快捷键」**，
右边有个按钮 **「设一个快捷键」**。
⚠️ **如果这条横幅没出现，捕捉这一整块就等于没有入口，告诉我。**

☐ **16.** 点「设一个快捷键」，会打开设置面板，而且**应该直接停在「快捷键」那一栏**
（因为还没绑，那是最要紧的一件事）。看到「捕捉快捷键」那一行，右边写着「未设置」。

☐ **17.** 点「未设置」那个按钮，它会变成「按键中…」，
然后**按你想要的组合键**。我建议先试 **`Ctrl + Alt + 空格`**。

☐ **18.** 按完之后，那个按钮应该显示成 **`Ctrl+Alt+Space`** 这样的字。
⚠️ **如果它显示成 `⌃⌥Space` 这种 Mac 符号，告诉我，那是我没改干净。**

☐ **19.** 如果它报错说系统拒绝了这个快捷键 —— 说明这个组合被别的软件占了。
**换一个再试**（比如 `Ctrl+Shift+空格`、`Ctrl+Alt+C`）。
**你最后用的是哪一个，告诉我，我记进文档。**

☐ **20.** 关掉设置。上面那条横幅应该**自己消失了**。

☐ **21.** 现在去别的软件（浏览器 / 记事本 / Word 都行），
选一段字，**按 Ctrl+C 复制**，然后**按你刚才设的那个快捷键**。

☐ **22.** 屏幕右上角应该弹出一个小卡片，里面是你刚复制的那段字。
⚠️ **卡片里应该有一行「来源」，写着你刚才那个软件的窗口标题**
（比如浏览器就是那个网页的标题）。**如果来源是空的，告诉我。**

☐ **23.** ⚠️ **这条是我明确没做的，先说在前面**：Mac 上卡片弹出来能**直接打字**，
**Windows 上大概率不行** —— Windows 不让后台程序抢键盘。
**你需要用鼠标点一下卡片里的笔记框，再打字。**
请确认：**点一下之后能打字，打的字按回车能存进去。**

☐ **24.** 卡片按 **Esc** 能关掉；不管它的话大概 8 秒自己消失。

☐ **25.** 回到 Spool 主窗口，**刚才捕捉的那条在项目里**。

### C. 打包

☐ **26.** 在一个有几条内容的项目里，点顶上的 **「打包」**。

☐ **27.** 打包出来的文字里，**如果有附件，只应该出现文件名**，
比如 `lecture-03.pdf`。
⚠️ ⚠️ **绝对不应该出现 `C:\Users\你的用户名\...` 这种完整路径。**
这是要粘给别人 AI 的东西。**看见完整路径立刻告诉我，这是隐私问题。**

☐ **28.** 左边栏在工作区那一行悬停，有个箱子图标（打包整个工作区），
点它 → 选个文件夹 → 导出。**导出的文件夹能打开，里面有 `INDEX.md` 和几个 `.md`。**

### D. MCP 接得上

☐ **29.** 设置 → **MCP** 那一栏。里面列着 Claude Desktop / Cursor / VS Code /
Claude Code / Codex 这些。

☐ **30.** 你 Windows 上装了哪个，它旁边应该显示 **「未配置」**；
没装的应该显示 **「未安装」**。
⚠️ **如果你明明装了某个客户端，它却说「未安装」，告诉我是哪个** ——
说明我猜的 Windows 路径不对。

☐ **31.** 对一个你装了的客户端点 **「一键接入」**，应该变成 **「已配置」**。

☐ **32.** **把那个客户端完全退出再打开**（重要 —— 它要重新启动 Spool 的服务）。

☐ **33.** 在那个客户端里问一句：**「我在 spool 里有哪些项目？」**
它应该能列出来。

☐ **34.** ⚠️ **这一条最关键，务必要做**：再说一句
**「把『这是 windows 上的第一条测试』存进 XX 项目」**（XX 换成一个真项目名）。

**为什么这条最关键**：读得出来 ≠ 写得进去。写入要生成一个随机 ID，
那段代码在 Windows 上是全新写的、从来没跑过。**如果它报「随机源不可用」，
立刻告诉我。**

☐ **35.** 回 Spool 看一眼，那条真的进去了。

## 第四部分：这些我知道是不行的，不用测

- **AI 维护 / 联网跟进那几个按钮** —— Windows 上整块是关着的，右栏不会出现，
  设置里那一栏「AI 引擎」也不显示。
  原因：点「取消」在 Windows 上停不掉整棵进程树，会留下还在计费、
  还攥着数据库的后台进程。这个要另做一版。
  ⚠️ **跟进清单本身还在**（面板、右栏、MCP 里加/关条目都正常），
  关掉的只是「让本机的 claude/codex 自己跑一轮」那条路。
- **双击 ⌥ / 双击 Alt** —— 不做（你定的）。
- **点卡片外面让它消失** —— 不做，用 Esc 或 ✕ 或等它自己走。
- **浏览器的「当前标签页标题」** —— Windows 上退成「窗口标题」，
  浏览器的窗口标题本来就带着标签页名字，够用。
- **设置里的「浏览器自动化权限」那一块** —— Windows 上直接不显示了（那是 Mac 的权限）。
