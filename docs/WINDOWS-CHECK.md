## 你问的：默认快捷键能不能是「双击 fn」

**不能，而且不是我不想做。** fn 那个键在绝大多数 Windows 笔记本上**根本走不到操作系统**——
它在键盘固件里就被吃掉了（按住 fn 再按 F5，系统只看得见「F5」或者「音量键」）。
所以没有任何软件能知道你「双击了 fn」，Spool 也不行。

「用复制和按键的时间差来辅助判断」这一步是对的，**Mac 上双击 ⌥ 就是这么做的**（10 秒内复制过才算）。
卡住的不是这个判断，是**那个键本身送不到软件手里**。

真要在 Windows 上做双击手势，只能是**双击 Ctrl 或双击 Alt**，而且要装一个全局键盘钩子
（`WH_KEYBOARD_LL`），杀毒软件容易把它当成键盘记录器。**你 08-15 定的「首版不做」我建议继续不做**;
想做的话单独开一轮,我先把杀软那一关查清楚再动手。
