## 2. 【待办 B】119 处死类名 —— 单开分支做，验完没问题再合

### 2.1 Ocean 的原话（2026-08-19）

> 「那 100 处死类名，**建一个分支去实现，没问题再合并**」

所以：**新分支**（建议 `fix/tailwind-alpha`），**从 `main` 开**（不是从 `valentine-edition`
开——这是主线缺陷，跟情人节没关系），做完给 Ocean 看改前改后，**他点头才合**。

### 2.2 病因（已确证，不用再查）

`tailwind.config.js` 里每个颜色都写成 `'var(--paper)'` 这种**完整颜色**的形式。
Tailwind v3 **没法**往一个 CSS 变量里注入 alpha 通道，于是遇到 `bg-ink/30` 这种
**它不报错，直接把整条规则丢掉**。构建全绿、tsc 全绿、测试全绿，什么都不说。

**取证方法（下一窗复核就用这个，别用正则，我第一次就是正则写错差点误判）**：

```bash
npm run build
cd dist/assets
# 字面搜，不是正则
for c in 'bg-ink\/30' 'hover\:bg-paper-2\/60' 'bg-accent\/10'; do
  printf '%-26s hits=%s\n' "$c" "$(grep -F -c "$c" main-*.css)"
done
# 整份 CSS 里带转义斜杠的类，应该只剩布局类
grep -o '[.][^{;, ]*\\/[0-9]*' main-*.css | sort -u
```

本窗结果：六个抽样全 `hits=0`；带转义斜杠的只有 `.left-1\/2` / `.-translate-x-1\/2`（布局类，无关）；
`color-mix` 出现 **0** 次（没有兜底）。

### 2.3 全清单：**119 处，39 个文件**

 9 border-accent/60   9 bg-paper-2/60      8 text-muted/70     8 bg-accent/15

重新生成：

```bash
grep -rhoE '\b(bg|text|border|ring|from|to|via|divide|placeholder|decoration|outline|shadow)-(paper|paper-2|paper-edge|ink|ink-2|muted|line|line-strong|accent)\/[0-9]+' src/ | sort | uniq -c | sort -rn
```

### 2.4 修法

把 token 改成**通道三元组**，config 里用 `<alpha-value>` 占位：

```css
/* tokens.css */
--paper-rgb: 250 247 240;
--paper: rgb(var(--paper-rgb));      /* 直接写 var(--paper) 的地方照旧能用 */
```
```js
// tailwind.config.js
paper: 'rgb(var(--paper-rgb) / <alpha-value>)',
```

⚠️ **两套都要留**：`tokens.css` / `global.css` / `fonts.css` 里有一堆地方是**直接**写
`var(--paper)`、`var(--accent)` 的（不走 Tailwind），把 token 改成纯通道值会**把那些一起弄坏**。
所以是「通道值 + 一个包好的完整颜色」两个 token 并存。

⚠️ **情人节那套 token 也要一起改**，否则修好之后**只有经典版**的透明度生效，情人节版还是死的。

## 4. 不要重做 / 不要推翻的（本窗已定）

- **经典版 = 发布版本身，不是一个「长得像旧版的主题」。** `tokens.css` 的裸 `:root` 不许动，
  情人节的一切都在 `[data-theme='valentine']` 里，默认 `classic`。
- **`--font-ui` 两个主题都是 Geist**（Ocean:「正常文字不变」）。只有标题字体换。
- **休息提醒和 Gwen 彩蛋只在情人节版**（Ocean 当窗回答的），经典版一个字节不变。
- **Gwen 故意不持久化**，关掉重开变回 Spool，理由在 `Wordmark.tsx`。
- **`--accent` 不是 `#e66d98`**，是它压暗降饱和的版本，因为原色对纸只有 2.84 : 1 撑不住小字。
  爱心用的才是原色。别「修正」回去。
- **搁置/紧急两个状态色故意没改**，它们必须和玫瑰色的 accent 一眼分得开。
- **换装必须先看现装的是什么签名**（`codesign -dvv /Applications/Spool.app | grep Authority`），
  看到什么就用什么。本机现在是**发布证书**，所以要
  `APPLE_SIGNING_IDENTITY="Developer ID Application: Hanze JIN (Q5Y5JRXZ58)" npm run tauri build -- --bundles app`，
  **且不改 `tauri.conf.json`**。装自签的那份会把授权弄没（见 [[isolated-verify-workflow]] §21②）。
- **`--mcp` 子进程一个都不要杀**（本机有 20 个，别的 AI 客户端起的）。停 GUI 按 pid 停，
  **绝不用模糊 `pkill -f spool`**。
