## 3. 不要重做 / 不要推翻的

**外观与主题**

- **经典版 = 发布版本身，不是「长得像旧版的主题」。** `tokens.css` 的裸 `:root` 不许动，
  情人节的一切都在 `[data-theme='valentine']` 里，默认 `classic`。
- **`--font-ui` 两个主题都是 Geist**（Ocean：「正常文字不变」）。只有标题字体换。
- **`--accent` 不是 `#e66d98`**，是它压暗降饱和的版本——原色对纸只有 2.84 : 1，撑不住小字。
  爱心用的才是原色。别「修正」回去。
- **搁置/紧急两个状态色故意没改**，它们必须和玫瑰色的 accent 一眼分得开。
- **Gwen 彩蛋故意不持久化**，关掉重开变回 Spool，理由在 `Wordmark.tsx`。
  ⚠️ **Gwen 仍然只在情人节版** —— 被推翻的是休息提醒那半条，不是这半条。

**休息提醒**

- **休息 5 分钟是写死的，工作时长（30/60/120）才是设置。** 论文三组的休息都是 5 分钟：
  5 是剂量，间隔才是排班。别把它也做成选项。
- **边栏面板主要在窗口失焦那一刻换面**，且 ≥30 秒一次。
  ⚠️ **「不要加当面换的兜底」这半条 2026-08-19 被 Ocean 推翻了**（§2.3 #4：「要，时间长一点」）——
  现在多一条 10 分钟的兜底，**它会当面换**，这是他知情换来的。失焦那条路本身没动。
- **锁屏一上来就把 DOM 焦点收走。** 不收的话人会继续往看不见的笔记里打字——
  这不是防御性代码，是这个交互本身要求的。

**更正与高亮（2026-08-19 下午这批，最容易被下一窗「修回去」）**

- ⚠️ **文件可读只认 `ai_access` 一把锁。** `include_in_pack` 退回它字面的意思：
  内联进**用户自己复制的那份 pack**。看到 `mcp.rs` 里没有 `|| include_in_pack`
  **不要「补回去」** —— 那正是 08-19 修掉的那句谎话（`DESIGN_PROJECT_FILES.md` §9）。
  ⚠️ 两个 pack 渲染器在这一点上**故意不一致**：golden 对照的是渲染函数（没动），
  分歧在喂给它的那一行数据。
- ⚠️ **`HIGHLIGHT_RE` 用 `[\s\S]` 不是 `.`。** 改回 `.` 会让跨行高亮存得进、读不回，
  屏幕上露出 `==`。这是「只能划一行」的病根之一。
- ⚠️ **选区一律走 `data-o` 映射，不许再用 `content.indexOf(选中的字)` 定位。**
  渲染器会吃掉 `**` / `==` / `## ` / 列表 `-`，字符串搜索对跨标记的选区必然失败。
  更正和高亮共用这一套（`selectionRange.ts`），**别给其中一个开小灶**。
- ⚠️ **更正折叠只在「读者够得着」时发生**：引文能定位、且目标不是合并块。
  放宽这个条件 = 造出一条进了 pack、屏幕上却看不见的块。
- **合并块（`SegmentedContent`）也要标偏移。** 它不走 Markdown 渲染器，
  漏了它就等于在那类块上把划词整个关掉。

**发布与装机**

- **换装前先看现装的是什么签名**（`codesign -dvv /Applications/Spool.app | grep Authority`），
  看到什么就用什么。本机是**发布证书**，所以要
  `APPLE_SIGNING_IDENTITY="Developer ID Application: Hanze JIN (Q5Y5JRXZ58)"`，
  **且不改 `tauri.conf.json`**。装自签的那份会把 TCC 授权弄没。
- **`--mcp` 子进程一个都不要杀**（本机常年二十来个，别的 AI 客户端起的）。
  停 GUI **按 pid 停**，绝不用模糊 `pkill -f spool`。
- ⚠️ **公证凭据要两样都有**：钥匙串里的 `spool-notary` profile 只够 `xcrun notarytool` 那步用；
  **Tauri 2.11 读不了钥匙串**，它只认 `APPLE_ID` / `APPLE_PASSWORD` / `APPLE_TEAM_ID`
  （或 API key 三件套）。`~/.spool-release-env` 留着别删。
- **构建日志要重定向到文件，不要接 `| tail`** —— `.app` 的公证 id 只在那一行 inline 输出里
  出现一次，接管道还会把退出码一起骗了。

**官网**

- ⚠️ **换了截图，压在图上面的东西要重新量**（`.zoom-box-*` 是图片高度的百分比）。
  框歪了页面看着还挺像回事，这才是容易发出去的原因。
- ⚠️ **换了截图，文件名没变，回头客看到的是旧图**（GitHub Pages `max-age=600`）。
  报「没生效」之前，先用 cache-buster 验一次服务器上到底是什么。
