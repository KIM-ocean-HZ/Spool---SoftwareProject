Spool（思簿）隐私政策

最后更新：2026-08-09（对应 Spool v0.4.0）

一句话版本

你的数据留在你的电脑上——没有例外。 Spool 是纯本地软件：捕捉、整理、打包、搜索全部在本机完成，不注册账号、不上传数据、不做遥测。Spool 自身不内置任何云端 AI，也不会向任何服务器发起请求；应用的内容安全策略（CSP）在结构上禁止了 webview 的一切外部网络连接。

我们收集什么

什么都不收集。 Spool 没有服务器。没有账号系统、没有使用统计、没有崩溃上报、没有广告标识符。开发者无法看到你的任何内容。

数据存放在哪里

  • 所有内容（工作区、项目、信息块、批注、附件索引）存放在本机的 SQLite 数据库：~/Library/Application Support/com.oceanjin.spool/spool.db
  • 界面设置存放在同目录的 settings.json（不含任何密钥——Spool 不需要）。
  • 附件本身不复制、不上传——Spool 只保存指向原文件的路径，以及（可选的）本地提取的文字内容。PDF/Word 的文字提取也完全在本机进行。
  • 数据库结构升级前会在同目录自动留存一份快照备份。

删除以上目录即可彻底清除 Spool 的全部数据；应用内「设置 → 清除所有数据」亦可。

什么时候会有数据离开你的电脑

Spool 自己一次都不出网。 有两种情况会让内容离开这台电脑，两种都默认关闭、需要你亲手开启，而且两种里出网的都是你自己装的、你自己登录的那个程序，不是 Spool：

功能数据去向说明
MCP 服务（设置 → MCP，默认关闭） 你自己安装、自己配置的 AI 客户端（Claude Desktop、ChatGPT 桌面版、Cursor 等） 你的 AI 客户端通过本机进程间通信读取项目内容；Spool 不监听任何网络端口。这些客户端把内容发给谁、如何使用，由该客户端及你与其服务商的协议决定。
AI 维护动作（设置 → 引擎，默认关闭） 你自己安装、自己登录的命令行 AI（Claude Code / Codex CLI） 点「压缩」「去重」「跟进」「周回顾」时，Spool 在本机启动那个 CLI 的子进程，把相关块的内容交给它。出网发生在那个子进程里——用的是你自己那个订阅账号的额度，Spool 不存任何 API key、不发任何 HTTP 请求。这个开关还要求 MCP 那两个开关都打开。

⚠️ 「跟进」这个动作会主动联网搜索。 它按你自己写的那几行「要盯什么」，让上面那个 CLI 去网上查有没有新进展——所以那几行字和它需要的上下文会到达 CLI 的服务商。其余三个动作只读你库里的内容，不开联网工具。

换句话说：Spool 从不主动外发数据。数据离开这台电脑，只可能是你装的那个 AI 程序在你的授权下读了内容——而「允许 AI 写入」还需要单独开启第二个开关。

系统权限说明

权限用途拒绝的后果
输入监听（双击 ⌥ 捕捉）识别 Option 键的双击手势双击 ⌥ 不可用；可在设置里自定义捕捉快捷键
辅助功能（可选）让捕捉手势只属于 Spool：捕捉发生时从事件流中移除第二次 ⌥ 按键，避免使用相同手势的其他应用（如 Claude Desktop）同时弹出捕捉一切照常；但相同手势的其他应用会与 Spool 同时被触发
自动化（浏览器）读取当前标签页标题作为来源标注来源退化为应用名
剪贴板捕捉时读取剪贴板文本无法捕捉

所有权限只在对应功能触发时使用，不做后台监控；剪贴板只在你按下捕捉快捷键的那一刻读取一次。
